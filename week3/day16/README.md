# Day 16 was about creating a Project. the project was to make a YT scraper using Qdrant VectorDB and RAG. generated the audio transcripts using yt-dlp and whisper from "padho with Pratyush" DSA playlist and store them in JSON format. Did the embedding and vectorized them and upsert them in Qdrant. Make a simple frontend to suppport the backend using FAST API. Ask the query or question about any DSA topic that is present in the series and taught, It will provide answer to that query along with transcript and timestamp to the exact part of the video along with small youtube video player on the website and a small summary of the asked quesry generated by LLM. LLM used is Gemini from AI studio. The Project is already made and pushed on Github.
